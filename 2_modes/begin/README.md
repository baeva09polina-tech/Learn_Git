# Code Assignment: Debug the Interactive Demo

## Objective

Review the code in this folder, identify any errors or inconsistencies, and fix them so the demo behaves as expected.

## Expected behavior

When a user clicks **Update Title**, the heading should change from **Welcome to the Demo** to:

> You clicked the button!

## Instructions

1. Review `index.html`, `script.js`, and `style.css` to understand how the page, styling, and button interaction fit together.
2. Run `index.html` in a browser and try the button. Compare what happens with the expected behavior above.
3. Inspect the code to find the cause of any discrepancy. Check the browser console for errors if needed.
4. Make the smallest changes needed to correct the behavior. Keep the existing page structure and styling unless you find a problem that requires changing them.
5. Reload the page and verify that clicking the button displays the exact expected heading text.

## Submission

Submit the corrected files and briefly describe the issue you found, the change you made, and how you verified the result.
