# Code Assignment: Debugging Task

## Objective
Your task is to identify and fix the errors in the code provided in the `begin` folder. The goal is to make the interactive demo work as intended.

## Instructions

1. **Understand the Code Structure**
   - The `begin` folder contains three files:
     - `index.html`: The main HTML file for the interactive demo.
     - `style.css`: The CSS file for styling the demo.
     - `script.js`: The JavaScript file for adding interactivity.

2. **Expected Behavior**
   - When the button is clicked, the text of the `<h1>` element with the ID `title` should change to: `"You clicked the button!"`.

3. **Identify the Errors**
   - Carefully review the code in all three files to find any syntax or logical errors that prevent the expected behavior.

4. **Fix the Errors**
   - Correct the errors in the code to ensure the demo works as described.

5. **Test Your Fixes**
   - Open the `index.html` file in a browser to verify that the button click updates the title text as expected.

## Hints

- Check for typos in function names and method calls.
- Ensure that the JavaScript code is correctly linked to the HTML file.
- Verify that the HTML elements referenced in the JavaScript code exist and have the correct attributes.

## Submission
Once you have fixed the errors, document the changes you made and why they were necessary. Submit the corrected code along with your documentation.
