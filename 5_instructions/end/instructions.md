## To-Do List Web App

### Overview
Build a simple To-Do List web application that allows users to manage their tasks.

### Requirements
- Users can:
  - Add new tasks
  - View existing tasks
  - Delete tasks
- Use browser's local storage to persist tasks
- The application should be responsive and user-friendly

### Technical Details
- Use HTML, CSS, and JavaScript
- No backend or external APIs
- All data should be stored in the browser's local storage
