# To-Do List Web App

## Overview
The To-Do List Web App is a simple and user-friendly application that allows users to manage their daily tasks efficiently. It is built using HTML, CSS, and JavaScript, and leverages the browser's local storage to persist tasks without requiring a backend server.

## Features
- **Add Tasks**: Users can add new tasks to their to-do list.
- **View Tasks**: All tasks are displayed in a list format.
- **Delete Tasks**: Users can remove tasks from the list.
- **Persistent Storage**: Tasks are saved in the browser's local storage, ensuring they remain available even after the page is refreshed.

## Technical Details
- **Frontend**: Built with HTML, CSS, and JavaScript.
- **Storage**: Uses the browser's local storage to save tasks.
- **Responsiveness**: The app is designed to be responsive and works well on various screen sizes.

## How to Use
1. Open the `index.html` file in a web browser.
2. Enter a task in the input field and click the "Add Task" button to add it to the list.
3. View your tasks in the list below the input field.
4. Click the "Delete" button next to a task to remove it from the list.

## File Structure
- `index.html`: The main HTML file containing the structure of the app.
- `styles.css`: The CSS file for styling the app.
- `script.js`: The JavaScript file containing the app's functionality.
