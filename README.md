# AI Programming with GitHub and Copilot in VS Code

This repository contains hands-on examples and exercises from a training course
on using GitHub and GitHub Copilot while developing in Visual Studio Code.

## Course sections

- `1_introduction/` — introductory example.
- `2_modes/` — examples exploring Copilot modes.
- `3_context/` — examples using project context, including a dynamic employee
  review page that loads records from `names.json`.
- `4_smart_actions/` — examples of Copilot smart actions and functions.
- `5_instructions/` — examples using instructions to guide Copilot.

Some sections contain `begin/` starter exercises and `end/` completed examples.
Each exercise folder includes its own HTML, CSS, JavaScript, or data files as
needed.

## Run the examples

Open the desired exercise's `index.html` in a browser. For exercises that fetch
local data such as JSON, run the folder through a local web server (for example,
the VS Code Live Server extension) instead of opening the file directly.
